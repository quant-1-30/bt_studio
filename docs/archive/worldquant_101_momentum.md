# WorldQuant 101 Alphas —— 动能类因子筛选与分析

> 来源:Zura Kakushadze, *101 Formulaic Alphas*, 2015-12-09(`worldQuant_101.pdf`)
> 论文原文说明:这些均为真实生产环境使用过的量化交易 Alpha,平均持仓周期约 0.6–6.4 天。

---

## 一、筛选方法

### 1. 过拟合过滤(剔除含"魔数系数"的因子)

**判定标准**:公式中含有**任意精度的小数系数**(如 `0.728317`、`3.92795`、`16.1219`、`0.00817205`)的因子被剔除。这类系数通常是参数寻优的产物,缺乏经济意义,大概率过拟合。

**豁免**:结构性常数不视为过拟合系数,包括:
- 整数或简单幂次:`2.`(平方)、`5`(五次方)
- 居中/归一化常数:`0.5`、`1.0`、`2`、`20`
- 简单阈值:`0.05`、`0.1`、`0.25`(条件判断逻辑中的整数刻度阈值)
- 数值保护项:`.001`(防除零)

**剔除结果(41 个)**:

| 区间 | 剔除原因 |
|---|---|
| #36 | 含 `2.21`、`0.7`、`0.73`、`0.6` 等多组任意权重系数 |
| #58、#59 | 含 `3.92795`、`7.89291`、`0.728317`、`16.2289` 等高精度系数 |
| #61 ~ #82 | 全部含高精度魔数(如 `16.1219`、`0.318108`、`0.518371`) |
| #84 ~ #99 | 全部含高精度魔数(如 `15.3217`、`0.876703`、`19.8975`) |

通过过滤的 60 个因子里,#60、#83、#100 核心是价格-量能相关性/日内位置结构,与动能无关,本文不展开。(边界说明:#100 含权重 `1.5`,为简单半整数而非任意精度系数,未计入魔数；若从严处理可一并剔除。)

### 2. 动能相关判定

保留核心构建块为**价格时序变动或趋势**的因子:`delta(close, d)`、价格时序排名 `ts_rank(close, d)`、收益符号累加、多周期收益差(动量价差)、趋势斜率等。按信号方向分为:

- **顺势(trend-following)**:信号方向与近期价格趋势一致
- **动量反转(contrarian-on-momentum)**:信号逆短期趋势(利用短期动量的均值回归),但构建块仍是动量项

最终入选 **19 个动能相关因子**。

## 二、动能因子详解

### A. 顺势类(趋势跟随)

#### Alpha#1 —— 近期高点位置(趋势新鲜度)

```
(rank(Ts_ArgMax(SignedPower(((returns < 0) ? stddev(returns, 20) : close), 2.), 5)) - 0.5)
```

**解释**:当昨日收益为负时用 20 日波动率替代收盘价,再取平方放大(SignedPower 2),然后看过去 5 天内**最大值出现在哪一天**(Ts_ArgMax)。若最大值出现在最近(值大),说明股价刚创短期新高、上涨动能"新鲜",做多；最大值出现在几天前则动能衰减。`-0.5` 使信号截面居中。本质是"新高距离"的趋势因子。

#### Alpha#7 —— 量能确认的 7 日动量(带波动抑制)

```
((adv20 < volume) ? ((-1 * ts_rank(abs(delta(close, 7)), 60)) * sign(delta(close, 7))) : (-1 * 1))
```

**解释**:条件因子。放量(当日成交量 > 20 日日均成交额 adv20)时:信号 = 7 日涨跌方向 `sign(delta(close,7))`(顺势),乘以 `-ts_rank(|Δclose₇|, 60)`——7 日变动幅度在 60 天中的分位越高,权重越低(抑制已暴涨暴跌的标的,避免追高)。缩量时直接看空(-1)。即"放量顺势、涨幅过大打折"。

#### Alpha#8 —— 动量的动量(加速度反转)

```
(-1 * rank(((sum(open, 5) * sum(returns, 5)) - delay((sum(open, 5) * sum(returns, 5)), 10))))
```

**解释**:构造 5 日累积收益×5 日开盘价之和的代理量 X,取 X 当前值与 10 日前之差——即"5 日动量本身的变化"(动量加速度)。取负排名:动能正在**加速**上涨的股票反而做空,动能**衰减**的做多。这是对"动量加速度"的均值回归。

#### Alpha#9 —— 趋势一致性过滤的 1 日动量

```
((0 < ts_min(delta(close, 1), 5)) ? delta(close, 1) : ((ts_max(delta(close, 1), 5) < 0) ? delta(close, 1) : (-1 * delta(close, 1))))
```

**解释**:若过去 5 天每日收盘价变动**全为正**(持续上涨),则跟随昨日动量做多 `delta(close,1)`；若 5 天全为负,跟随做空；否则(方向紊乱)反转昨日变动。用"趋势一致性"作为开关,决定顺势还是逆势。

#### Alpha#10 —— #9 的截面排名版

```
rank(((0 < ts_min(delta(close, 1), 4)) ? delta(close, 1) : ((ts_max(delta(close, 1), 4) < 0) ? delta(close, 1) : (-1 * delta(close, 1)))))
```

**解释**:与 #9 逻辑相同(窗口改为 4 天),但外层套 rank 做截面排名,信号变为相对强度,更平滑、更适合组合构建。

#### Alpha#24 —— 长期横盘判定下的位置动量

```
((((delta((sum(close, 100) / 100), 100) / delay(close, 100)) < 0.05) || ((delta((sum(close, 100) / 100), 100) / delay(close, 100)) == 0.05)) ? (-1 * (close - ts_min(close, 100))) : (-1 * delta(close, 3)))
```

**解释**:先算 100 日均线相比 100 日前的变化率。若变化率 ≤ 5%(长期横盘或慢牛),做多"距离 100 日低点的反弹空间"(`-(close - ts_min(close,100))` 取负后,离低点越远值越低……实际为反转 100 日区间位置)；否则(趋势明确时)做空 3 日短期变动(短期反转)。阈值 `0.05` 为简单刻度,属结构性常数。

#### Alpha#52 —— 经典长周期动量价差 + 支撑抬升 + 量能确认

```
((((-1 * ts_min(low, 5)) + delay(ts_min(low, 5), 5)) * rank(((sum(returns, 240) - sum(returns, 20)) / 220))) * ts_rank(volume, 5))
```

**解释**:三项相乘:
1. `delay(ts_min(low,5),5) - ts_min(low,5)`:5 日最低价较 5 天前的变化——支撑位抬升为正(趋势健康向上),创新低为负；
2. `rank((240日收益 − 20日收益)/220)`:**经典的 12 月−1 月动量价差**(剔除最近一个月,规避短期反转效应),这是学术上最稳健的动量定义(Jegadeesh & Titman 1993)；
3. `ts_rank(volume, 5)`:量能时序排名确认。
三个维度同向共振时信号最强。

#### Alpha#101 —— 标准化日内动量(论文明确标注的动量因子)

```
((close - open) / ((high - low) + .001))
```

**解释**:日内涨幅除以日内振幅(`.001` 防除零),即标准化后的日内收益。论文原文明确指出:"Alpha#101 in Appendix A is a delay-1 momentum alpha: if the stock runs up intraday (i.e., close > open and high > low), the next day one takes a long position in the stock."——今天日内跑赢的股票,次日继续做多。是全文唯一被作者亲自标注为动量的因子。

### B. 动量反转类(基于动量项的逆向信号)

#### Alpha#14 —— 3 日收益加速度反转 × 量价相关

```
((-1 * rank(delta(returns, 3))) * correlation(open, volume, 10))
```

**解释**:`delta(returns,3)` 是 3 日收益的变化(加速度),取负排名:收益正在加速恶化的做多、加速改善的做空(短线过度反应的修正),再乘开盘价与成交量的 10 日相关系数调节方向与强度。

#### Alpha#17 —— 趋势 × 加速度 × 量能 三重反转

```
(((-1 * rank(ts_rank(close, 10))) * rank(delta(delta(close, 1), 1))) * rank(ts_rank((volume / adv20), 5)))
```

**解释**:三项相乘:
1. `-ts_rank(close,10)`:10 日价格趋势反转(价格越接近 10 日高点越做空)；
2. `rank(delta(delta(close,1),1))`:价格加速度；
3. `rank(ts_rank(volume/adv20,5))`:量比放大程度。
趋势、加速度、量能三个动量维度复合的逆向信号。

#### Alpha#19 —— 7 日动量反转 × 年度收益加权

```
((-1 * sign(((close - delay(close, 7)) + delta(close, 7)))) * (1 + rank((1 + sum(returns, 250)))))
```

**解释**:`sign` 项等价于 `sign(7日涨幅)`,取负——一周动量反转(赌超涨回吐、超跌反弹)；权重 `(1 + rank(1+250日收益))` 使过去一年累计收益高的股票反转信号更强。

#### Alpha#30 —— 3 日趋势一致性反转 × 量比

```
(((1.0 - rank(((sign((close - delay(close, 1))) + sign((delay(close, 1) - delay(close, 2)))) + sign((delay(close, 2) - delay(close, 3)))))) * sum(volume, 5)) / sum(volume, 20))
```

**解释**:核心项是**连续 3 天涨跌符号之和**(取值 -3 ~ 3,衡量 3 日趋势一致性)。`1 - rank(·)` 后:3 日一致性上涨的股票反而低配(一致性反转)。乘以 5 日/20 日量比——放量时该反转信念更强。

#### Alpha#31 —— 多周期动量反转的衰减平滑组合

```
((rank(rank(rank(decay_linear((-1 * rank(rank(delta(close, 10)))), 10)))) + rank((-1 * delta(close, 3)))) + sign(scale(correlation(adv20, low, 12))))
```

**解释**:10 日动量反转项经两层 rank + 10 日线性衰减加权(decay_linear)平滑,加上 3 日动量反转项,再加 `sign(scale(corr(adv20, low, 12)))`(20 日均额与低价的相关性方向)作为整体偏置。多周期反转的稳健合成。

#### Alpha#38 —— 10 日趋势反转 × 日内强度

```
((-1 * rank(Ts_Rank(close, 10))) * rank((close / open)))
```

**解释**:`-ts_rank(close,10)`:收盘价在 10 日内的时序排名取负(趋势反转),乘以当日 `close/open` 的截面排名(日内强度)。两个动量维度都强的(连涨 + 当日强)反而做空——典型的短期均值回归。

#### Alpha#39 —— 7 日动量反转 × 量能异常度 × 年度收益加权

```
((-1 * rank((delta(close, 7) * (1 - rank(decay_linear((volume / adv20), 9)))))) * (1 + rank(sum(returns, 250))))
```

**解释**:与 #19 同族。7 日价格变动乘以 `(1 − rank(decay_linear(volume/adv20, 9)))`——量能异常放大时衰减动量项(放量大涨更可能是真趋势,反转需谨慎),整体取负排名做反转,再按 250 日累计收益加权。

#### Alpha#43 —— 量比时序确认的 7 日反转

```
(ts_rank((volume / adv20), 20) * ts_rank((-1 * delta(close, 7)), 8))
```

**解释**:7 日价格变动的反转项 `-delta(close,7)` 取 8 日时序排名,乘以量比的 20 日时序排名——**放量时反转信号更强**,缩量时信号趋弱。两个时序排名相乘使信号天然处于 [-1,1] 区间且稳健。

#### Alpha#46 —— 动量减速检测(斜率差条件因子)

```
((0.25 < (((delay(close, 20) - delay(close, 10)) / 10) - ((delay(close, 10) - close) / 10))) ? (-1 * 1) : (((((delay(close, 20) - delay(close, 10)) / 10) - ((delay(close, 10) - close) / 10)) < 0) ? 1 : ((-1 * 1) * (close - delay(close, 1)))))
```

**解释**:构造**趋势斜率差**:前段斜率(20 日前→10 日前)减去近段斜率(10 日前→现在)。
- 斜率差 > 0.25:近期明显**减速**(涨势衰竭)→ 做空(-1)；
- 斜率差 < 0:仍在**加速** → 做多(1)；
- 之间:反转昨日变动。
用"加速度"而非"速度"择时,是动量生命周期因子。`0.25`/`0` 为刻度阈值,属结构性常数。

#### Alpha#49 —— #46 变体(加速阈值 -0.1)

```
(((((delay(close, 20) - delay(close, 10)) / 10) - ((delay(close, 10) - close) / 10)) < (-1 * 0.1)) ? 1 : ((-1 * 1) * (close - delay(close, 1))))
```

**解释**:与 #46 同一斜率差。斜率差 < -0.1(明确加速上涨)→ 做多；否则做空昨日涨幅。相当于 #46 去掉"减速做空"分支、只保留"强加速做多"的更严苛版本。

#### Alpha#51 —— #46 变体(加速阈值 -0.05)

```
(((((delay(close, 20) - delay(close, 10)) / 10) - ((delay(close, 10) - close) / 10)) < (-1 * 0.05)) ? 1 : ((-1 * 1) * (close - delay(close, 1))))
```

**解释**:与 #49 完全同构,仅加速判定阈值放宽为 -0.05(更容易触发做多分支)。#49/#51 成对出现说明作者在做阈值敏感性——两式都保留可以交叉验证。
